# Arquivos Lumière Odonto

Vídeos do Instituto Lumière (Mafra/SC) para o site, em MP4 H.264 1080p vertical (9:16), prontos para tocar em qualquer navegador.

Endereço base: https://eduardoschuman-glitch.github.io/Arquivos-Lumiere-Odonto/

Galeria para testar todos os vídeos: https://eduardoschuman-glitch.github.io/Arquivos-Lumiere-Odonto/

## Como usar no site

```html
<video controls playsinline preload="metadata" poster="https://eduardoschuman-glitch.github.io/Arquivos-Lumiere-Odonto/depoimentos/depoimento-joao.jpg" style="width:100%;max-width:420px;aspect-ratio:9/16;">
  <source src="https://eduardoschuman-glitch.github.io/Arquivos-Lumiere-Odonto/depoimentos/depoimento-joao.mp4" type="video/mp4">
</video>
```

Cada vídeo tem uma capa .jpg com o mesmo nome, para usar no atributo poster.
